# Egress allowlist for scripts/egress_audit.py (make egress-audit).
#
# The audit scans our own code (the platform image's /app) and what the web image ships to the
# browser (server.js, .next/server, .next/static, public) and fails on any host named there that is
# not listed here. One pattern per line: `*.example.com` matches subdomains only, anything else is
# an exact host. Every entry says why it is harmless; a blank line ends a comment block.
# `# optional: <name>` opens a section that only applies with --allow-optional <name>.
# Runtime egress is enforced separately by NetworkPolicy / the firewall; this is build-time evidence.

# ---------------------------------------------------------------- GM Financial tenant services
# Entra ID: sign-in authority and token endpoints (OIDC), also the default authority written into
# generated solutions' appsettings.
login.microsoftonline.com

# Key Vault data plane: secrets read at runtime.
*.vault.azure.net

# GMF's Azure OpenAI resources: the only model endpoint when the Claude provider is off.
*.openai.azure.com

# Azure Resource Manager: the deploy step's Terraform / az calls.
management.azure.com

# Azure Database for PostgreSQL flexible server.
*.postgres.database.azure.com

# The token audience ("https://cognitiveservices.azure.com/.default") requested from Entra for
# Azure OpenAI in api/app/services/providers.py. It is an OAuth scope string, never fetched.
cognitiveservices.azure.com

# ------------------------------------------------- names that appear in our code but are never fetched

# Placeholder outputs for Terraform dependency mocks (engine/infra_gen/generator.py _mock_outputs):

# Kubernetes label keys and API group names in the Terraform modules we generate

# Suffixes the static rules use to skip XML namespace hosts (engine/analysis/static_rules.py
