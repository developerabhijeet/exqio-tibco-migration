# Public samples

These are public TIBCO BusinessWorks sample sets, used only for parser breadth tests
(never as demo material for customers). Each zip is kept alongside its unzipped copy.

| Directory | Source | Format | Licence |
|---|---|---|---|
| `GMF_PoC_1_BW6_CreditApp_TN2018/` | github.com/TIBCOSoftware/bw-samples (folder TN2018/Apps) | BW6 | TIBCO Samples Internal End User License (internal use only; legal check before any customer showing) |
| `GMF_PoC_2_BW5_BW6_tibcobwblog/` | github.com/tibcobwblog/tibcobwblog_samples | BW5 + BW6 | None declared (internal learning and parser testing only) |
| `GMF_PoC_3_BW5_codereview_Apache2/` | github.com/fastconnect/tibco-codereview | BW5 | Apache 2.0 |
| `GMF_PoC_4_Extractor_Toolkit/` | RSI-authored `extract_ir.py` plus the parsed inventory of sets 1 to 3 (not a public source) | Python/JSON | RSI internal |

Each directory keeps its own README and licence files. Set 4 is the RSI proof-of-concept
toolkit rather than a public sample, so treat it as internal.
