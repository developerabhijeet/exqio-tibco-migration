Overview

Generated from design v2 of dealerfunding.DealerFundingRequest. Edits made on this page are replaced on the next publish.

The dealer funding request arrives on a queue and is checked against the dealer and the deal before a funding row is written.

A duplicate request is logged & dropped; a funding event is published for downstream ledgers.
